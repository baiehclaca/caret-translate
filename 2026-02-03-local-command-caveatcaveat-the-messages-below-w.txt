⏺ CaretTranslate Overview

  CaretTranslate is a native macOS 15.0+ (Sequoia) menu bar translation utility
  written in Swift.

  Purpose

  A privacy-focused translation tool that sits in the system status bar,
  allowing users to translate text anywhere on the system without leaving their
  current application. It uses Apple's native Translation framework.

  Architecture

  CaretTranslate/
  ├── App/                 # UI layer (28 Swift files) - SwiftUI settings,
  status bar, monitors
  ├── Core/                # Business logic (14 Swift files) - translation
  service, selectors
  ├── CaretTranslateTests/ # 17 test files with 50+ test cases
  └── Packages/CoreMLPipelines/  # Experimental LLM support (not integrated)

  Key Features

  - 3-tier translation fallback: Mixed-language word → Sentence → Word
  - Dual activation modes: Double-tap or hotkey shortcuts
  - Privacy controls: App allowlist/denylist by bundle ID
  - Translation history with retention policies
  - Preview/confirmation dialog before text replacement
  - Debug logging window for troubleshooting

  Technologies

  - Swift (async/await, @MainActor)
  - Apple Translation framework (macOS 15+)
  - NaturalLanguage framework (language detection)
  - AppKit + SwiftUI

⏺ Design Section 2: Helper Binary (caret-translate-nllb)

  Language: Python with CTranslate2 bindings (faster to develop, easy model
  management)

  Protocol: Line-delimited JSON over stdin/stdout

  → Input (one line):
  {"text": "Hello world", "source": "en", "target": "sv"}

  ← Output (one line):
  {"translation": "Hej världen"}

  ← Error (one line):
  {"error": "Unsupported language pair"}

  Lifecycle:
  1. App spawns helper on first NLLB translation request
  2. Helper loads model into memory (~2-3 seconds cold start)
  3. Helper stays alive, processing requests until app terminates
  4. Subsequent translations are fast (~50-150ms)

  Model: NLLB-200-distilled-600M with int8 quantization
  - Size: ~300MB on disk
  - Memory: ~600MB when loaded
  - Coverage: 200+ languages

  Bundling: The helper + model gets bundled in the app's Resources folder, or
  downloaded on first use to ~/Library/Application Support/CaretTranslate/.
